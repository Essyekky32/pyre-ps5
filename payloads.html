PYRE / LAUNCH PAYLOADS

Send a payload

Every card below is a working button. Pressing one downloads that file from this PC, checks it against the catalogue, and pushes it to your console's ELF loader. It also files the payload into PYRE Payloads, so you can launch it again from the manager later — including after a restart. All of them ship beside Pyre.exe, so there is nothing to download and nothing to upload.

This is not RUN PYRE. It starts no exploit: no kernel stage, no kstuff, no ShadowMountPlus, no etaHEN. If the console is not already jailbroken in this session, every button fails fast with a plain explanation and sends nothing.
Open this page the same way you reached PYRE — normally through the console's User's Guide. Payloads are checksum-verified, and that check is only available on a secure page.
