PYRE / AUTOLOADER

Install the PYRE autoloader

This page does one thing: it pushes our-payloads/pyre-autoloader-installer_v0.5.2-pyre.elf to your console's ELF loader, so the console installs the PYRE autoloader — the permanent entry point that brings the exploit back after a restart.

This is not RUN PYRE. It sends no exploit sequence: no kstuff, no ShadowMountPlus, no etaHEN, no Payload Manager, no App Dumper and no browser installer. For the normal sequence, go back and press RUN PYRE on the PYRE menu.
It needs the console already jailed in this session: the loader it talks to (port 9021) only exists once the exploit has been run. If the loader is not answering, this page says so plainly and stops — it cannot start the exploit for you.
